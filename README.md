Customer Retention & Churn Analysis

Project Overview

This project analyzes eCommerce customer behavior to understand shopping patterns, customer retention, and potential customer churn.

Problem Statement

Understanding customer shopping behavior and identifying inactive customers can help businesses improve customer engagement and retention.

Objectives

- Analyze customer shopping activities.
- Identify customer purchase patterns.
- Calculate monthly customer retention.
- Identify potentially inactive customers.
- Recommend strategies to improve customer retention.

Dataset

eCommerce Behavior Data from Multi-Category Store.

Source: https://www.kaggle.com/datasets/mkechinov/ecommerce-behavior-data-from-multi-category-store

Tools Used

- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn

Analysis Performed

- Exploratory Data Analysis
- Customer purchase analysis

- Customer activity analysis
